Create a concise Obsidian-friendly handoff note for this session.

Format:
# Handoff - <short task name>

## Status
- Done / In progress / Blocked:

## What changed
- 

## Files touched
- `path`: why

## Tests / checks
- command: result

## Important decisions
- 

## Open questions / follow-ups
- 

## Suggested next prompt
```text
Continue from this handoff. Goal: ...
```

Be specific enough that a new pi session can continue without re-reading the whole chat.
